# Digital-techniques2
Course project CPU design in SystemVerilog, and complete lab work files from Digital Techniques 2 course at University of Oulu.

The language used is SystemVerilog (a hardware description language), which is employed for implementing the RTL architecture
and for debugging. 

All design tasks are executed on the university's (University of Oulu) Linux computing servers,
(Linux remote desktop program, particularly Lehmus VDI desktop/ server).

More description on ProjectOverview file.
